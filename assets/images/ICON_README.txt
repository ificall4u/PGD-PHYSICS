PGD Physics — App Icon (final direction)
========================================
Mark: Rounded square (~25% corner radius)
Fill: Gradient #7C5CFC → #6D4AE8 (top-left to bottom-right)
Glyph: White graduation cap (Icons.school_rounded / equivalent vector)
No text on icon. Name sits under the icon on the launcher.

Splash + in-app header use the same AppMark widget for consistency.
For Play Store / APK: export 1024×1024 PNG from this spec, then
flutter_launcher_icons for mipmaps.
